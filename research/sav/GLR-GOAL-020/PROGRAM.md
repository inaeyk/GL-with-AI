# Technical program

1. In the fixed graph problem \(L_{\rm RW}w_0=0\), the mixed polarization pair is driven by fixed GL geometry times \(w_0\), and \(4w_{2,uv}+Vw_2=F_u+G_v-H\) includes both mixed and direct-plus-mean terms. With constraint-induced upper graph jets the three solves are linear in the free axial graph profile.
2. Carry commuted positive flux estimates and weighted coefficient rows through the compact wedge and exterior. Treat the packet bound as an absolute operator estimate, separate from a candidate-error certificate.
3. Polarize \(\mathcal P_I[h]=\langle N_{01}[h],N_{21}[h]\rangle_I\), use the directed endpoints, and bound prefix variation to locate a zero in a common bracket.
4. For finite amplitudes carry the two-parameter matched trace and derive a conditional sign theorem using explicit error norms. Check amplitude, parity, exact energy and admissible profile changes independently.
